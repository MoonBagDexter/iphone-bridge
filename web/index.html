Custom Button setup — no web page

Records on the phone and sends it here. Nothing opens on screen, so this is the one to put on the Action Button.

  1. Open Shortcuts, tap +
  2. Add Record Audio. Tap Show More and set Start Recording to On Tap — tap once to start, again to stop.
  3. Add Get Contents of URL and set:
    • URL — the address below
    • Method — POST
    • Headers — add x-bridge-pin set to your bridge PIN
    • Request Body — File, then pick Recorded Audio
  4. Name it Dictate, then Settings → Action Button → Shortcut → Dictate

Transcription runs on this PC and the text is typed into whatever window has focus, plus copied to the PC clipboard. Nothing leaves your machine.
